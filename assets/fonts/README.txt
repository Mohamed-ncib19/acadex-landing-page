Fonts served by the site itself
===============================

cairo-arabic.woff2, cairo-latin.woff2
  Cairo (variable, weights 400-900), Arabic and Latin subsets.
  Copyright 2016 The Cairo Project Authors (https://github.com/Gue3bara/Cairo)

plus-jakarta-sans-latin.woff2
  Plus Jakarta Sans (variable, weights 400-800), Latin subset.
  Copyright 2020 The Plus Jakarta Sans Project Authors (https://github.com/tokotype/PlusJakartaSans)

Both are licensed under the SIL Open Font License, Version 1.1:
https://openfontlicense.org/open-font-license-official-text/

The files are the subsets Google Fonts serves (fonts.gstatic.com), unmodified.
A file is never replaced under the same name: the host caches this folder for
a year. A new version of a font gets a new file name.
