## La différence en une phrase

Un logiciel cloud tourne sur un serveur distant et s'utilise dans un navigateur. Un logiciel hors ligne est installé sur votre ordinateur, et vos données y restent.

## Comparaison

| Critère | Hors ligne (installé sur le PC) | Cloud (dans le navigateur) |
| --- | --- | --- |
| Connexion Internet | Pas nécessaire pour travailler | Indispensable |
| Où sont les données | Sur votre ordinateur | Chez le fournisseur |
| Paiement | Souvent un achat unique | Souvent un abonnement |
| Accès depuis plusieurs lieux | Non : un poste | Oui |
| Sauvegardes | À votre charge | Faites par le fournisseur |
| Si le PC tombe en panne | Il faut une sauvegarde hors du PC | Rien à restaurer |

## Quand le hors ligne convient

- Une seule personne, ou un seul bureau, saisit les données.
- La connexion est lente ou coupe souvent.
- Vous préférez payer une fois plutôt que tous les mois.
- Vous voulez garder les données dans l'établissement.

## Quand le cloud convient mieux

- Plusieurs sites, ou des personnes qui travaillent à distance.
- Les parents ou les professeurs doivent se connecter eux-mêmes.
- Personne dans l'établissement ne veut s'occuper des sauvegardes.

## Le point faible du hors ligne, et comment le couvrir

Tout repose sur un ordinateur. La parade tient en une habitude : une copie régulière des données hors de l'ordinateur, sur une clé USB, un disque externe ou dans le cloud.
